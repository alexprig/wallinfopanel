Configure the panel over USB (Web Serial, 115200 baud) · Admin page

Not connected
Web Serial is not available in this browser. Use Chrome or Edge on a desktop computer, and open this page via http://localhost:5080/setup/ or https.
Turn the panel's setup switch ON, press RST, plug in USB, then click Connect and pick the "USB-SERIAL CH340" port.
